@locale id
;; A6 Indonesian number format: `.` groups thousands, `,` is the decimal mark
1.000 + 2.500 => 3.500
1,5 * 2 => 3
10.000,5 + 0,5 => 10.001
1.234.567 => 1.234.567
2,5 km in m => 2.500 m
20% of 1.000.000 => 200.000
1.000 / 3 => 333,333333
gaji = 8.500.000 IDR => 8.500.000 IDR
gaji * 12 => 102.000.000 IDR
50 + 10% => 55
0,1 + 0,2 => 0,3
---
@locale id
;; In id, a comma between digits is the decimal mark, not grouping
1,234 => 1,234
12,5 % of 200 => 25
---
@locale id
;; A misplaced grouping dot is an error, not a different number
1.23.4
